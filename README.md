# Лабораторная работа №2 — Генератор билетов

Веб-приложение с тёмным «экзаменационным» интерфейсом. Логика та же:
парсинг `students.xlsx` / `tickets.docx`, идемпотентная выдача билета, журнал `results.xlsx`.

Десктопный Tkinter сохранён: `python main.py --desktop`.

## Установка

Нужен Python 3.9+ :

```bash
pip install -r requirements.txt
```

Tkinter входит в стандартную поставку Python (на Linux иногда нужен `python3-tk`).

## Запуск

Положите `students.xlsx` и `tickets.docx` в корень проекта.
Тестовые файлы можно создать так:

```bash
python scripts/make_sample_data.py
python main.py
```

Откройте в браузере [http://127.0.0.1:5000](http://127.0.0.1:5000).

## Как пройти тесты кнопками

1. В шапке откройте вкладку **Тесты**.
2. Нажмите **Запустить все тесты** — прогонятся все 13 unit-тестов из `tests/test_lab2.py`.
3. Либо запускайте каждый тест своей кнопкой **Запустить**.

Это те же проверки, что и в консоли:

```bash
python -m unittest tests.test_lab2 -v
```

UI-сценарии (клики в браузере через Selenium):

```bash
python -m unittest tests.test_ui_selenium -v
```

Нужны Google Chrome и Selenium (драйвер подтягивается автоматически).

## Структура проекта

```
main.py              — точка входа (веб по умолчанию)
app/
  parsing.py         — парсинг students.xlsx и tickets.docx
  storage.py         — чтение/запись results.xlsx
  logic.py           — назначение билета
  gui.py             — интерфейс на Tkinter
  web.py             — Flask API и страница тестов
templates/           — разметка веб-интерфейса
static/              — стили и скрипты
tests/
  test_lab2.py       — 13 unit-тестов
  test_ui_selenium.py
```

## Соответствие критериям приёмки

- Первый список — листы students.xlsx, второй — студенты выбранной группы.
- Кнопка «Сгенерировать билет» активна только когда выбраны и группа, и студент.
- Окно результата показывает «Ваш билет № N» и три вопроса.
- Повторный выбор того же студента возвращает тот же билет.
- ESC закрывает только окно результата и возвращает к выбору.
- Запись в results.xlsx происходит сразу после генерации.
- Отсутствие файлов или занятый results.xlsx показываются сообщением, без падения.
- Билеты с некорректным заголовком или < 3 вопросов пропускаются.
- Пустая группа: второй список пуст, кнопка неактивна.
