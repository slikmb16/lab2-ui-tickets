# Лабораторная работа №2 — веб-генератор билетов

Веб-приложение выдаёт экзаменационные билеты студентам: читает группы и ФИО
из Excel, вопросы из Word и сразу сохраняет всю историю выдач в Excel-журнал.

## Возможности

- Группы загружаются из листов `students.xlsx`, студенты — из выбранной группы.
- Кнопка генерации активна только после выбора группы и студента.
- Новый студент получает случайный билет, повторный — тот же номер.
- Результат показывает номер и три вопроса; `Esc` закрывает только окно билета.
- `results.xlsx` хранит хронологическую историю, включая повторы.
- Вкладка «Тесты» объясняет каждую проверку: сценарий, критерий и ожидаемый результат.
- Сообщения об отсутствии входных файлов и блокировке журнала в Excel понятны пользователю.

## Установка

Требуется Python 3.9+.

```bash
pip install -r requirements.txt
```

## Входные файлы

`students.xlsx` и `tickets.docx` должны находиться в корне проекта, рядом с
`main.py`.

### students.xlsx

Каждый лист — отдельная группа. Имя листа — название группы. Первая строка
содержит заголовки, с второй строки: колонка A — фамилия, B — имя.

### tickets.docx

```text
Билет 1
1. Первый вопрос
2. Второй вопрос
3. Третий вопрос
```

Билет с неверным заголовком или менее чем тремя вопросами пропускается, а
остальные билеты продолжают использоваться.

Для создания демонстрационных входных файлов:

```bash
python scripts/make_sample_data.py
```

## Запуск

```bash
python main.py
```

Откройте [http://127.0.0.1:5000](http://127.0.0.1:5000). Остановка сервера —
`Ctrl+C` в терминале.

## Ручная проверка

1. На вкладке «Генерация» выберите группу и студента, затем выдайте билет.
2. Убедитесь, что показаны номер и три вопроса. Закройте окно через `Esc`.
3. Выберите этого же студента снова: номер совпадает, появляется пометка о повторе.
4. На вкладке «Журнал» проверьте новые строки: первая выдача — «нет», повтор — «да».
5. Выберите пустую группу (лист с одними заголовками): список студентов и кнопка неактивны.
6. Временно переименуйте `students.xlsx` или `tickets.docx` и нажмите «Проверить файлы». Интерфейс укажет отсутствующий файл. Верните имя и проверьте снова.
7. Откройте `results.xlsx` в Excel и попробуйте выдать билет. Появится сообщение о необходимости закрыть файл; приложение продолжит работать.

## Тесты

Во вкладке «Тесты» доступны запуск одной проверки и «Запустить все тесты».
Каждая карточка содержит сценарий, связанный пункт требований и ожидаемый
результат.

Те же тесты запускаются из терминала:

```bash
python -m unittest discover -s tests -p "test_lab2.py" -v
python -m unittest tests.test_ui_selenium -v
```

В проекте 15 unit-тестов и 4 Selenium UI-теста: парсинг Word/Excel, пустая
группа, повторная выдача, история журнала, отсутствие источников, блокировка
журнала и пользовательский сценарий.

## Формат results.xlsx

Журнал создаётся автоматически. Новые записи дописываются в конец и не
изменяют существующие строки.

| Группа | Фамилия | Имя | Номер билета | Дата и время | Повтор |
| --- | --- | --- | --- | --- | --- |
| ИС-21 | Иванов | Иван | 2 | 2026-09-17 10:15:00 | нет |
